# Roadmap: v0.1 → Steam

Honest scope: a complete, great RPG is 18–36 months of team work. This plan gets to a **paid-quality vertical slice fast**, then scales content. Dates are relative to kickoff (K).

## Phase 0 — First Ember (this repo, done in v0.1)
Core systems + tests + graybox playable loop + CI. CEO: create the Unity project, open once, commit metas, add Unity CI secrets, play the graybox.

## Phase 1 — Vertical slice (K + 4–8 weeks)
One real biome (Sunken Archive): room tileset, 3 enemy types with final telegraphs, first shard boss (1 phase), Bastion hub corner (Smith + Emberkeeper), ember economy live, real save/load UI, options menu (accessibility set), Input System asset with rebinding UI. **Gate: 10 external playtests; combat clarity score ≥ 4/5.**

## Phase 2 — Content engine (K + 2–6 months)
Room-tile pipeline + 3 more biomes, 12 skills, affix crafting, quest chain 1, memory vignettes ×10, music layer 1, controller-only full pass, Steam Deck perf pass (60 fps @ 800p).

## Phase 3 — Steam presence (parallel from K + 2 months)
CEO steps (money & accounts — all yours): Steamworks partner account, pay the **$100 Steam Direct fee** per app → App ID → we wire `steamworks-setup` (App ID file, guarded Steam assembly), achievements + cloud saves through the seam, store page from our drafted text/art, Content Survey (we must declare any AI-generated shipped content — decide before review). Fixed waits after the fee: **21 days** before release eligibility, store page review (~2–5 business days), Coming Soon must be public **≥ 14 days**, build review (~3–5 business days), price review. Plan backwards from launch day; I'll produce the dated plan when you pick a day.

## Phase 4 — Demo & Next Fest
Public demo (own App ID) = vertical slice + 1 boss. Next Fest once per game; demo review 3 weeks before the fest. Wishlists from the demo drive launch.

## Phase 5 — Launch (K + 12–24 months realistic)
7 shards, 3 endings, full accessibility pass, localization (EN first, +EL/DE/FR/ES/zh-CN by wishlist geography), Deck Verified submission, launch discount decision (yours), rollback plan (previous build id noted).

## Budget lines the CEO owns
Steam Direct fee ($100/app), any paid art/audio assets or contractors, Unity plan if revenue thresholds are crossed, optional playtest incentives. Nothing is spent without your Approve.
