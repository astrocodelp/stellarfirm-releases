# Steam title — collision research (2026-11-22)

"Emberfall" is taken on Steam: at least three apps use it
([app 3301890](https://store.steampowered.com/app/3301890/Emberfall/),
[app 4447800](https://store.steampowered.com/app/4447800/), and app 2373440 with live updates).
The working title must change before the Steamworks page is created.
Sources: Exa web search, store.steampowered.com results, checked 2026-11-22.

## Clean candidates (no exact match found in web search)

1. **Gloamcrown** — coined word, zero exact hits anywhere. "Gloam" (twilight) + the Hollow Crown;
   says fading light + fallen kingdom in one word. Unique search term = free SEO.
2. **The Ember Tithe** — no exact hits. Names the core mechanic: the Hollow taxes your light,
   kills pay it back. Distinctive, but "tithe" is a harder word for global audiences.
3. **Emberrend** — no exact hits, but reads close to Skyrim's "Chillrend" fan chatter; weaker.

## Recommendation

**Gloamcrown** (subtitle: *Chronicle of the Hollow Crown* stays).
Before committing: a proper trademark screen (USPTO/EUIPO class 9/41) and a domain check —
web search is not a legal clearance. The Steamworks app name can still be changed until release.

Internal code namespace (`Emberfall.*`), assembly names and repo folder stay as the codename;
only the display name (window title, productName, Steam page, marketing) changes.
